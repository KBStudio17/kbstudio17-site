# KB Studio 17 Website

Static HTML/CSS website for KB Studio 17.

## Upload
Upload all files and the complete `assets` folder to the GitHub repository root, then commit.

## Don’t Buck Nature ordering link
In `dont-buck-nature.html`, replace the disabled “Ordering Link Coming Soon” link with the final print-on-demand product URL and remove `disabled-link`, `aria-disabled`, and `onclick` from that anchor.

Before launching sales, replace the temporary donation statement with the exact donation percentage or amount and the named recipient organization.


## Don’t Buck Nature store setup

The selected print-on-demand provider is Fourthwall. After publishing the shirt product in Fourthwall, replace the placeholder `href="#"` in `dont-buck-nature.html` with the permanent Fourthwall product URL. Fourthwall supports customer checkout using PayPal and Apple Pay on compatible devices and browsers. The campaign page states that 100% of net profits from shirt sales are donated.
